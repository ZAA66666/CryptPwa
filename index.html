    使用教程

    点开下面的卡片，照着「怎么用」一步步做就行。每个都给了实例，边看边练最快上手。

    ① 哈希（Hash）—— 给数据算个“指纹”

    是什么：把任意长度的文本，变成一串固定长度的字符（指纹）。不可逆——算出来就回不去原文。哈希不需要密码，所以算完也不会弹出“存密码本”。

    怎么用：

    1. 在「哈希」页粘贴文本（如 hello）；
    2. 选算法（推荐 SHA-256；只有 HMAC 系列才需要填“密钥”）；
    3. 点「计算哈希」→ 复制结果。

    举个栗子：SHA-256("hello") =
    2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824

    注意：MD5 / SHA-1 已不安全，只拿来做非机密的完整性校验（比如比对文件有没有传错），别当密码保护用。

    ② 编/解码（Base64 / Hex / URL / Base32 / Base58 / Unicode / JWT）—— 不是加密！

    是什么：只是把数据换一种写法，可逆、不需要密钥。它不是加密，谁都能还原。

    怎么用：在「编/解码」页选方式（如 Base64 编码）→ 输入 →「执行」。

    举个栗子：Base64("hello") = aGVsbG8=。Base32 / Base58 常用于分享密钥、区块链地址；Unicode 转义便于在代码里嵌中文；JWT 是带签名的令牌（可看 header/payload）。

    注意：编码 ≠ 加密。想保密请用下面的「加/解密（对称） / 非对称加/解密」，别把密码只做 Base64 就当保护了。

    ③ 加/解密（AES / DES / 3DES / Blowfish / RC4 / Rabbit）—— 对称：一把密钥

    是什么：加密和解密用同一把密钥。适合你知道对方、能安全把密钥告诉他的情况。

    怎么用：

    1. 选算法（优先 AES，最通用最安全）；
    2. 填密钥（注意下面的长度提示：AES 要 16 / 24 / 32 字节，DES 8 字节，3DES 24 字节）；
    3. 选分组模式：ECB（最简单、无需 IV，但最不安全）；CBC 等需要填 IV；
    4. 输入明文 / 密文 →「加密」或「解密」。

    注意：流密码（RC4 / Rabbit）密钥长度任意、没有模式/IV。DES、3DES、ECB 模式已不推荐用于真实机密。

    ④ 非对称加/解密 · RSA / SM2 —— 一把公钥、一把私钥

    是什么：一对钥匙：公钥（可公开，用来加密 / 验签）+ 私钥（自己藏好，用来解密 / 签名）。

    怎么用（对方给你发密信）：

    1. 进入「加/解密」页，顶部类别切到「非对称加密」，会自动生成密钥对（顶部显示「已生成密钥对」）；
    2. 点「查看/修改密钥对」在弹窗里查看、复制或重新生成公钥/私钥；
    3. 把公钥发给对方；
    4. 对方在「加密」里用你的公钥加密，把密文发你；
    5. 你选「解密」、用私钥解开。

    签名（证明是你发的）：你选「签名」用私钥对文本签名 → 对方选「验签」用你的公钥验证。

    注意：① 需运行在 https 或 localhost 环境；② 2048 位单次最多加密约 190 字节；③ 私钥绝不能泄露。

    ⑤ 二维码 & 条形码 —— 把文字/链接变成可扫的图

    是什么：把文本、网址等变成一张能被手机扫出来的图（二维码）；也能生成条形码（商品条码、Code128 等机器可读线条）。

    怎么用：在「二维码 / 条形码」页，顶部切「二维码 / 条形码」：

    • 二维码：填内容（如网址）→ 选纠错等级 →「生成二维码」→ 可「下载 SVG」或「扫描二维码」。
    • 条形码：填内容（如 123456789012）→ 选格式（CODE128 / EAN13 等）→「生成条形码」→ 可下载 SVG。

    注意：纠错等级越高越抗污损但图案越密；条形码请按用途选对格式（商品用 EAN-13，通用用 CODE128）。

    ⑥ SM2 国密 —— 已并入「加/解密」页（类别选「非对称加密」→ 算法选 SM2）

    是什么：和 RSA 一样是非对称算法（公钥加密 / 私钥解密，私钥签名 / 公钥验签），但符合中国国家密码标准（国密），密文格式为 C1C3C2。

    怎么用：进「加/解密」页，顶部类别切到「非对称加密」，算法选 SM2，会自动生成密钥对（顶部显示「已生成密钥对」）。点「查看/修改密钥对」在弹窗里查看、复制、重新生成，也可「保存到密码本」；私钥建议弹窗外的「保存到文件」本地保管。选「加密 / 解密 / 签名 / 验签」→ 输入 →「执行」。

    适合：对接国内政务、金融等要求国密的场景。与 RSA 的区别主要在算法标准和密钥格式。

    ⑦ JSON 工具 —— 格式化 / 提取 / 键值编辑

    是什么：对 JSON 做整理和加工，不加密。

    • 格式化：把压缩的 JSON 美化缩进；压缩：去掉空格变一行；校验：检查是否合法。
    • 提取代码：填 JSON + 键路径（如 user.name），生成对应语言的取值代码。
    • 键值编辑：像表格一样逐行加键和值，选类型后一键生成 JSON，也可从格式化区导入。
    ⑧ Crontab —— 写定时任务表达式

    是什么：用一行 5 段表达式描述“什么时候执行”，常用于定时任务（如每天备份）。

    怎么用：在「Crontab」页写表达式（或点下面的常用示例）→「解析 / 校验」会告诉你接下来 5 次执行时间。

    格式：分 时 日 月 周。例 */15 9-17 * * 1-5 = 工作日 9–17 点每 15 分钟。点开「怎么写」有详细说明。

    ⑨ 随机文本生成 —— 字符串 / 虚假数据

    是什么：快速造测试数据，不加密。

    • 随机字符串：勾选字符范围（数字/大小写/特殊符号）、设长度、可加正则约束、设数量，一键生成。
    • 随机虚假数据：一键生成姓名、邮箱、手机号、身份证、地址、公司、UUID、网址、银行卡、颜色、日期等常见“假数据”，适合填表/造样例。

    注意：这些都是随机/虚构数据，仅用于测试，不含真实个人信息。

    ⑩ 基础概念小抄
    • 明文：还没处理的原始内容；密文：加密后的乱码。
    • 密钥 / 密码：加密用的“钥匙”，千万别用同一个当密码。
    • 可逆 vs 不可逆：加密、编码能还原；哈希不能还原。
    • 该用哪个：校验完整性→哈希；让数据能传输→编码；你和对方都要看原文且要保密→加/解密（对称）；只给对方看、怕中间人→非对称加/解密（RSA / SM2）。
